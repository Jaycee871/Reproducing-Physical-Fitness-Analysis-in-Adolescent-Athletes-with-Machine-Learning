01 · Reproduction Target

我們要重現什麼？

Lee 等人（2024）以男性青少年運動員的體適能指標，利用機器學習區分不同運動項目。原研究的主要結果來自 5 種運動兩兩配對，共形成 10 組二元分類。

二元分類：一次只判斷兩個類別，例如「田徑 vs 足球」。

研究問題

  • 公開的論文、程式碼與資料，是否足以重新建立主要分析流程？
  • 原論文 XGBoost 的約 90% 平均準確率，能否接近重現？
  • Paper、Code、Data 三者是否完全一致？

公開資料概況

1,434資料筆數
15體適能特徵
5運動類別

類別：足球 537、田徑 402、棒球 328、游泳 105、羽球 62。

缺失值 0　｜　完全重複資料 0

核心專有名詞

XGBoost由多棵決策樹逐步修正錯誤的分類模型。
Accuracy模型預測正確的比例，也就是準確率。
SMOTE替少數類別產生新的訓練樣本，降低類別不平衡。
StandardScaler把不同單位的數值調整到相近尺度。

重建流程

公開 CSV：1,434 × 16
↓
X / y 分離：15 個體適能特徵 + 運動類別
↓
80 / 20 分層切分（保持各類別比例）
↓
StandardScaler 或 MinMaxScaler
↓
SMOTE：只作用在訓練資料
↓
XGBoost → 10 組運動 pair
↓
與原論文 Accuracy / AUROC / F1 比較

兩種公開材料重建路徑

A. 論文文字流程

全資料分層切分 → 取兩種運動 → MinMaxScaler（−1 到 1）→ SMOTE → XGBoost

B. 公開 Notebook 流程

先取兩種運動 → 分層切分 → StandardScaler → SMOTE → XGBoost

防止資料洩漏

資料洩漏：測試資料提前影響模型訓練，會讓結果看起來不真實地更好。

  • Scaler 只用 training data 學習。
  • SMOTE 只補 training data。
  • Test set 不參與資料補樣。

04 · Reproducibility Findings

哪些地方無法完全對上？

樣本數不一致
Abstract 1,489；Methods 與公開 CSV 為 1,434。
X / y 建立流程缺失
Notebook 使用 teen_running_soccer 與 teen_runsoc_target，但未公開如何建立。
Scaling 描述不一致
論文描述 −1 到 1；公開 notebook 使用 StandardScaler。
Hyperparameter search 不完整
論文提到 1,000 次 random search，但 10 組最佳參數未完整公開。

Reproduction Status

Close reconstruction supported

主要 10 組 XGBoost 結果可利用公開材料重建到接近原論文的程度，但不足以宣稱完全相同的 execution-level replication。

這代表什麼？

  • 主要結果具有相當程度可重建性：89.20% 接近原論文約 90.14%。
  • 公開材料仍不完整：無法證明作者原始 pipeline 每一步都被完全復原。
  • 重現研究的價值：不只是「把程式跑起來」，還要找出 paper、code、data 的一致與不一致。

GitHub 自動化證據

GitHub ActionsRe-runnableVersioned

主要流程皆可由 GitHub Actions 重新執行：資料檢查、Paper–Code–Data audit、前處理重建、模型比較與 10-pair XGBoost reproduction。

真正執行模型的程式：
reproduction/run_10pair_xgboost.py

結論

本研究利用公開資料、程式碼與 GitHub 自動化流程，成功重建原研究最核心的 10 組 XGBoost 二元分類。公開 notebook 流程得到 89.20% 平均準確率，與原論文約 90.14% 接近。

因此，本研究定位為：高度接近的公開材料重建，而不是完全相同的原始執行環境複製。

原始研究：Lee, Y.-H. et al. (2024). Essential elements of physical fitness analysis in male adolescent athletes using machine learning. PLOS ONE 19(4): e0298870.

註：原論文文字報告平均 Accuracy 約 90.14%；以本文表格 10 組數值重新平均約為 90.15%，屬四捨五入差異。
