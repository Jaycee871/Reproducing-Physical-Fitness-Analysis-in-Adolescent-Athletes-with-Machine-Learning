1重現目標

原研究利用體適能特徵辨識男性青少年運動員的運動種類。本研究聚焦於最重要的 10 組 pairwise binary classification，檢驗公開 paper、code 與 dataset 是否足以重建主要 XGBoost 結果。

  • 五種運動兩兩配對，共 10 組二元分類。
  • 比較論文描述與公開 notebook 兩種可重建流程。
  • 不以猜測補上未公開的 class mapping 與 pair-specific search history。

6兩條可重建路徑

A｜Paper-description

全資料先 stratified 80/20 split → select pair → MinMaxScaler(−1, 1) → SMOTE → XGBoost

B｜Public-notebook

先 select pair → pair-specific split → StandardScaler → SMOTE → XGBoost

固定公開 configuration：n_estimators=147, max_depth=8, max_features=0.353969, random_state=42。

7資料洩漏防護

Scaler 僅在 training data 上 fit；SMOTE 也只作用於 training data；test set 不參與補樣。這避免測試資料提前影響模型學習。

11主要重現差異

樣本數不一致Abstract = 1,489；Methods 與 public CSV = 1,434。
X / y 生成步驟缺失公開 notebook 使用 teen_running_soccer / teen_runsoc_target，但沒有定義其建立過程。
Scaling 描述不一致論文描述 −1 到 1；公開 notebook 使用 StandardScaler。
搜尋歷史未完整公開1,000-epoch random search 的 10 組 pair-specific 最佳參數無法完整復原。

12哪些部分成功重建？

可重跑的公開重現鏈

公開 dataset 可取得；資料檢查、前處理、baseline、模型比較與 10-pair XGBoost 均可由 GitHub Actions 重新觸發。

  • 10 組 pairwise task 可執行。
  • Public-notebook mean accuracy 接近原論文。
  • 結果、差異與限制均有版本紀錄。

13結論

高度接近的公開材料重建

公開 notebook 路徑得到平均 Accuracy 89.20%，與原論文約 90.14% 接近。

但由於 X/y 建立、numeric class mapping、scaling 描述與完整 hyperparameter-search history 不完整，本研究不宣稱完全相同的 execution-level replication。

TAKEAWAYS
核心結果接近

Public-notebook reconstruction = 89.20%，與 paper 約 90.14% 相差 0.94 pp。

方法可重跑

GitHub Actions 保存資料檢查、前處理與模型執行路徑。

公開材料有落差

樣本數、scaling 與 pair-specific search 資訊並不完全一致。

研究定位清楚

Close reconstruction，重現主要 empirical pattern，不過度宣稱完整複製。
